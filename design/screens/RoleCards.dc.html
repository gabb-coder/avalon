Anatomy of a front

  1. Private label: lock + “Only you can see this”, top centre.
  2. Emblem frame: circle = Good, diamond = Evil.
  3. Role name: Cormorant 36.
  4. Team tag: icon + word, filled ink.
  5. Ability: one sentence, plain words, 14px.
  6. Night info: names only. Evil names get a crimson ring; “Merlin?” candidates get a teal ring.

Shown only while held. Release = instant hide (no fade), so a glance away is safe.
