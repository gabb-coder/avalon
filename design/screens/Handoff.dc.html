Avalon · developer handoff · v1

Build notes for a vanilla HTML/CSS/JS app

Everything on this canvas is drawn with one stylesheet, rt.css, which ships as-is: tokens, components and icons (inline SVG as CSS masks). No images, no icon font, no framework. This page lists the tokens, every component and its states, layout metrics, motion, accessibility and the decisions I made where the brief was open.

Shell

Root element is .phone at width: 100%; height: 100dvh in production (fixed 390×844 only on the canvas). Order inside: topbar → status → content (scrolls) → dock. Add env(safe-area-inset-*) to topbar top and dock bottom padding. The dock rides above the keyboard via visualViewport.
